# moyu —— 极简桌面悬浮看板

一个运行在 Windows 桌面上的极简悬浮小窗，用于常驻显示某个实时行情数值。窗口无边框、半透明、始终置顶，用大字号把关键数字直接摆在桌面上，不占任务栏、不打断工作。

## 功能特点

- **极简悬浮窗**：无边框（`overrideredirect`）、85% 半透明、始终置顶，不显示在任务栏中。
- **大字号显示**：字号随窗口高度自动计算，数字始终撑满窗口，远距离也能一眼看清。
- **每秒自动刷新**：后台线程每 1 秒请求一次接口，界面平滑更新，不卡顿。
- **拖动即走**：按住左键即可把窗口拖到桌面任意位置。
- **悬停出现关闭按钮**：鼠标移入时右上角浮现 `✕`，移出自动隐藏，平时不遮挡数字。
- **右键菜单自定义**：可更改背景颜色、字体颜色，并提供 4 档预设窗口尺寸。
- **秒退**：点击 `✕` 或双击窗口即刻结束进程（`os._exit(0)`），不会残留后台线程报错。

## 默认外观

| 项目 | 默认值 |
| --- | --- |
| 背景色 | `#2c3e50`（深灰蓝） |
| 字体色 | `#e74c3c`（红色） |
| 透明度 | 85% |
| 窗口尺寸 | 260 × 100（“中”） |
| 初始位置 | 屏幕右上角 |

## 环境要求

- **操作系统**：Windows（依赖 tkinter 的窗口属性）
- **Python**：3.10 及以上
- **依赖库**：仅 `requests`，其余均为标准库

> 需要 Python 官方安装包默认勾选 `tcl/tk` 组件。可在命令行验证：
> ```bat
> python -c "import tkinter; print(tkinter.TkVersion)"
> ```

## 安装

```bat
:: 1. 进入项目目录
cd G:\moyu2

:: 2.（可选）创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

:: 3. 安装依赖
pip install -r requirements.txt
```

离线环境可先下载再安装：

```bat
pip download -r requirements.txt -d ./packages
pip install --no-index --find-links ./packages -r requirements.txt
```

## 运行

```bat
python main.py
```

窗口会出现在屏幕右上角，约 1 秒后显示第一笔价格；若此时网络异常，会显示 `超时` / `断网` / `解析错误` 等提示，恢复后自动变回数值。

### 开机自启（可选）

按 `Win + R` 输入 `shell:startup`，把下面内容的 `moyu.bat` 放进打开的启动文件夹：

```bat
@echo off
cd /d G:\moyu2
start "" pythonw main.py
```

用 `pythonw` 可让程序在后台运行，不弹出黑色命令行窗口。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 按住左键拖动 | 移动窗口位置 |
| 鼠标移入窗口 | 右上角显示关闭按钮 `✕` |
| 鼠标移出窗口 | 关闭按钮隐藏 |
| 单击 `✕` | 立即退出程序 |
| 双击窗口 | 立即退出程序 |
| 右键单击 | 弹出菜单：更改背景颜色 / 更改字体颜色 / 窗口大小 / 退出 |

窗口大小的 4 档预设（宽 × 高）：小 180×70、中 260×100、大 360×140、超大 480×180。切换时会保持窗口中心位置不变。

## 数据来源

程序以 POST 方式请求接口：

- **地址**：`https://mbmodule-openapi.paas.cmbchina.com/product/v1/func/market-center`
- **请求体**：`[{"prdType":"H"}]`
- **取值路径**：`data.FQAMBPRCZ1.zBuyPrc`，按两位小数显示

接口返回示例（节选）：

```json
{
  "code": "SUC0000",
  "data": {
    "FQAMBPRCZ1": {
      "zBuyPrc": "759.84",
      "zSelPrc": "754.84"
    }
  },
  "success": true
}
```

## 常见问题

**窗口看不到？**
先确认进程是否还在运行。程序启动后位于屏幕右上角（初始坐标由 `main.py` 中 `_build_window` 按屏幕宽度计算）。若因多显示器或缩放比例较大被挤到屏幕外，结束进程后重新运行即可回到初始位置。

**数字一直是“断网”或“超时”？**
检查网络与代理；接口仅在内网/特定网络环境可访问时，需要先连上对应网络。超时时间由 `REQUEST_TIMEOUT`（默认 3 秒）控制。

**关闭按钮点不到？**
移入窗口后按钮出现在右上角，若窗口过小导致按钮与数字重叠，右键切换到更大的预设尺寸即可。

**改了颜色想恢复默认？**
右键 → 更改背景颜色，输入 `#2c3e50`；字体颜色输入 `#e74c3c`。

## 注意事项

- 颜色与尺寸设置仅对当前运行生效，重启后回到默认值。
- 程序通过 `os._exit(0)` 直接结束进程，不触发窗口销毁流程，因此不会保存任何状态。
- 右键菜单沿用系统样式，不跟随背景/字体配色，以保证可读性。
